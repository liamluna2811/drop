# Thème Shopify — Bandeja Club

- `theme/` : code du thème (Online Store 2.0). Le zip `bandeja-club-theme.zip` contient le même contenu, prêt à être importé (Boutique en ligne > Thèmes > Ajouter un thème > Importer un fichier zip).
- `product-images/` : 18 visuels de t-shirts (un par produit et par couleur), à utiliser comme photos produit.
- `products.json` : catalogue (titres, prix, couleurs) utilisé pour créer les produits.

Chaque produit a deux options : **Couleur** (1re option) puis **Taille**. Le thème affiche les pastilles de couleur à partir du nom de la couleur (Nuit, Forêt, Noir, Blanc, Sable, Ciel, Lime). Pour une autre couleur, ajoute-la dans `theme/snippets/color-hex.liquid`.
